# Тестовое задание на должность - Фронтенд разработчик React

Приложение для отправки и получения сообщений WhatsUp через сервис GREEN API

## Инструкция для локального запуска

В настройках уведомлений инстанса GREEN API включите параметр:
`Получать уведомления о входящих сообщениях и файлах`

Клонируйте репозиторий командой:

```bash
git clone https://github.com/ouldanov/green_api_whatsup.git
```

Добавьте в проект файл .env с переменной:
`VITE_API_URL=*Адрес апи инстанса(apiUrl)*`
apiUrl - Можно посмотреть в настройках инстанса

Установите зависимости проекта командой:

```bash
npm install
```

Запустите проект командой:

```bash
npm run dev
```

## Инструкция по использованию

В окне авторизации введите `ID инстанса (idInstance)` и `Ключ доступа (apiTokenInstance)`, эти параметры можно посмотреть в настройках инстанса GREEN API

После появится экран отправки сообщений, введите:

- номер телефона кому хотите отправить сообщение;
- текст сообщения;
  и нажмите кнопку отправить.
